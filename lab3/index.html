Dataset description, Data Source and Number of Records

This dataset contains the flight records for Hong Kong International Airport (HKG) on August 31st, 2026, covering both arrivals and departures across passenger and cargo services. Each record represents one flight and includes its scheduled date and time, direction, service type, primary flight number and airline, codeshare details, origin or destination airport, and latest status. The Date and Scheduled Time columns contain official scheduled values, while Status reports the latest actual or estimated flight event.

Data acquired programmatically from the airport's public flight information API using a Python script (requests). The four API requests returned 1,109 flight records for the target date August 31, 2026.

API documentation: Flight Information DataSpec.pdf
API URL: https://www.hongkongairport.com/flightinfo-rest/rest/flights/past
